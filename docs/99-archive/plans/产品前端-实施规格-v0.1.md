## 1. 目标与非目标

**目标**：把「调试工作台」变成业务用户可直接使用的智能问数产品入口——以对话为主交互，澄清 / 审批 / 结果 / 历史全部产品化；治理页面原样收进后台分组，不新增管理功能。

**非目标**：移动 App、国际化、会话协作分享、消息编辑撤回、可视化配置器、管理面功能增强、SSO 对接（列 M8）。

## 2. 用户与核心旅程

| 角色 | 旅程 | 高标准要求 |
|---|---|---|
| 业务用户 | 打开首页 → 看到示例问题 → 提问 → （澄清点选 / 审批确认）→ 流式结果（表 + 图）→ 追问 → 次日从历史继续 | 首问零学习成本；错误说人话；等待有进度感；结果可自解释（指标 / 口径 / 时间窗标注） |
| 数据 / 平台管理员 | 治理后台：清单发布、失败看板分诊、审计检索 | 现状保留，仅导航收纳 |
| 开发者 | 对话页开发者视图：事件日志、DSL、执行计划回放 | 折叠不干扰，URL 可直达 |

## 4. 通道架构（本规格最重要的设计决定）

**现状问题**：`POST /ask/runs`（同步终态，30s 后 waiting）与 `GET /agui/run/{agentId}`（SSE 过程流）是两条独立通道，调试页各用各的——产品化必须合并为一个事实源。

**v0.1 方案**（待 R1 审核挑战）：

1. **对话主通道 = AG-UI SSE**（`GET /agui/run/{agentId}` 或 POST 发起，D1 spike 确认具体形态）：流式文本（`TEXT_MESSAGE_*`）、执行步骤（`TOOL_CALL_*` 脱敏摘要）、终态重建（结构化终态经 `CUSTOM` / `RUN_FINISHED` 载荷，PoC #3 已验证五类终态 100% 可重建）；
2. **`POST /ask/runs` 保留两个职责**：澄清回传（`clarificationChoice`）与审批回传后的续跑；响应中的 `runId` 用于续接 SSE；
3. **终态事实源 = SSE 重建**，POST 响应仅作回执与 `runId` 取回；两者不一致以 SSE 为准（事件重放幂等可仲裁）；
4. 断线重连：SSE 断开后经 `GET /ask/run/{runId}/events?afterSeq=` 续播（后端已实现幂等重放），不重复触发审批 / 查询（PoC #10 判据延续）。

## 5. 事件 × UI 映射（六类事件 + 五类终态）

| 事件 / 载荷 | UI 呈现 | 约束 |
|---|---|---|
| `RUN_STARTED` | 会话轮开始（用户消息气泡已在位） | `input` 字段前端不展示、不上报（A.4 脱敏） |
| `TEXT_MESSAGE_START/CONTENT/END` | 助手消息流式渲染（打字机） | 增量拼接；中断可继续 |
| `TOOL_CALL_START/ARGS/RESULT` | 执行步骤指示器（「正在执行查询…」级摘要，不展示原始参数） | 参数与 SQL 永不出现在产品 UI（开发者视图除外） |
| `CUSTOM`（终态载荷） | 终态卡渲染（§6 终态卡） | 载荷 schema 与 POST 终态一致 |
| HITL interrupt | 审批内联卡（批准 / 拒绝 / 备注） | 置顶 + 输入禁用 |
| `state` | 会话态徽标（场景内 / 澄清中 / 等待审批） | 随会话态机（M5 三态） |
| 终态 `query` | 结果表 + 元信息条（指标 / 口径 / 时间窗 / 行数）+ 图表（W4） | `degraded=true` 时显示「结果来自确定性检索（未走大模型）」人话文案 |
| 终态 `composite` | 子结果分组卡（每子卡同 query 呈现） | `subResults` 结构契约待附录补齐（R1 审） |
| 终态 `clarification` | 澄清四要素卡：歧义文案 + 候选点选 + 自定义输入 + 默认建议 + 跳过降级 | 点选回传协议见 §6.2 |
| 终态 `discovery` | 能力清单卡（指标 / 维度 / 模式三组，可点选发起） | 空数组给「暂无可查资产」空态 |
| 终态 `out_of_capability` | 拒答文案卡（copy_template 渲染）+ 原因码 | 不暴露内部码，文末「查看可查资产」入口 |
| 服务端拒绝（code≠0） | 错误卡：中文人话（copy_template）+ 重试按钮 | 业务码 / 网络错误分开呈现 |

## 6. 页面组件分解

### 6.1 对话主页

- `ConversationStream`：消息列表（用户 / 助手 / 系统卡），按轮组织；长会话虚拟滚动；
- `Composer`：多行输入、Enter 发送 / Shift+Enter 换行、发送中禁用（run 进行中禁发——M5 R3 会话锁）、停止跟随按钮；
- `TerminalCard`（5 类，替换现雏形）：见 §5；
- `ClarificationCard`：四要素；点选回传协议 = `{ choice: assetId }` / `{ choice: "__default__" }` / `{ choice: "__skip__" }`（后端 `clarificationChoice` 契约核对列 R1 审）；
- `ApprovalCard`：M4 审批单摘要 + 批准 / 拒绝 + 备注；
- `ResultTable`：500 行上限内前端分页（50 / 页），列排序，CSV 导出（D7 约束下导出= 内存生成即时下载）；
- `ResultChart`（W4）：形状映射（1 维 → 柱；含时间列 → 线；0 维单值 → 大数字卡）；零基线规则 / 单位与口径标注 / 行数 < 3 只给表；
- `SessionStateBadge`：三态徽标；
- `EmptyState`：示例问题 3–5 个（来源 = discovery 通道 + 资产摘要生成，任务列 W6）；
- `ErrorCard` + `RetryButton`。

### 6.2 会话历史（D4=a）

- `SessionList`：按会话聚合（首问截断为标题、最近时间、轮数）；后端新增 `GET /api/v1/ask/sessions`；
- `SessionReplay`：只读重放（复用对话流渲染器，输入区隐藏）；复用 `GET /ask/run/{runId}/events` 幂等重放。

### 6.3 登录（D3=a）

- `LoginPage`：用户名 + 密码 + 租户选择；后端新增 `/api/v1/auth/login` 签发 M4 认证上下文 token（任务 W-B2）；401 统一跳转登录（`request.ts` 已有文案）。

### 6.4 开发者视图（D8=a）

- 现 `/ask` 四面板整体迁移为对话页右侧折叠抽屉，仅 `dev` 角色可见；URL `?dev=1` 直达。

## 7. 非功能标准

- **性能预算**：首字（SSE 首事件→UI）≤ 2s；500 行表格首次渲染 ≤ 500ms；TTI ≤ 3s；测量 = Playwright trace（W9）；
- **无障碍**：全键盘可达、焦点顺序、澄清卡点选可 Enter 激活、对比度 AA；
- **安全**：D7 缓存策略；所有回传字段服务端唯一裁决（前端输入视为不可信）；SSE 断线重连不重复触发（幂等判据延续）；
- **兼容**：Chrome / Edge 最新两个大版本；≥768px 两档断点（D6=a）；
- **深色模式**：设计 token 已具备，首版默认浅色，深色列 Backlog（R1 审）。

## 10. 风险与回退

| 风险 | 回退 |
|---|---|
| CopilotKit 无法纯浏览器直连 | D1 退路 = @ag-ui/client 自研渲染（现状雏形即此路线，风险可控） |
| 会话历史 / auth 后端排期冲突 | W-B1/W-B2 为小任务（各 ≤2 天）；不可用时 W5/W8 降级为 Backlog，其余包不受阻 |
| 图表需求蔓延 | D5 只做三类；新图表类型一律走变更评审 |
| SSE 经网关缓冲 | 交叉引用 M8 网关任务（禁缓冲 / 心跳 / 超时对齐） |
| 模型延迟长导致体验差 | 首字预算依赖模型 TTFB——产品文案「正在分析…」步骤指示器兜底；不承诺模型侧延迟 |

## 11. 与 M8 / 评测（C-1）的关系

- 本规格与 M8 上线工程并行，不互相阻塞；网关任务需吸收 SSE 透传要求；
- ×3 轮评测（C-1）与本规格互不阻塞；评测配置纪律（干净工作区 + retrieval 词表域）已在本规格 §4 的产品默认中采纳为建议值；
- workspace 记忆全局共享（P1 隔离发现）在本规格的落点：**产品登录态与 workspace 隔离方案联动定档**（W-B2 时一并决策）。
