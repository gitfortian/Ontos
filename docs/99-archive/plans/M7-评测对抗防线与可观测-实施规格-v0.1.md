## 1. 目标与非目标

**目标**（roadmap M7）：用自有评测证明效果，而不是靠演示。

1. **评测可信**：正式评测集与 gold 冻结且带版本哈希；指标按 `scenario_entry_mode / query_shape / turn_type / risk_type` 分层统计并给置信区间；**评测结果可由版本与数据哈希复现**。
2. **LLM 路径评测**（E-7）：在稳定模型服务上跑通同一 test 集，给出与确定性降级路径**分口径**的统计、成本与失败分类；不混口径、不以降级结果冒充。
3. **对抗防线专项**：注入、跨轮差分、跨域组合、能力边界、discovery 五类，加 LLM 路径新攻击面；安全违规为 0 的硬门槛。
4. **失败看板闭环**：5 维下钻 + 失败样本根因分类 + **纠正样本自动回流**（状态流转、回流 API、回归集写入、集合隔离）。
5. **可观测与 SLO**：复用 OTel/Studio + Actuator（不自研埋点），trace 关联问题 → DSL → SQL → 结果，并覆盖 LLM 调用与成本；P95 / 成本 / 并发 SLO 压测。
6. **补齐 M6 报告的代码类附条件项（四项）**：纠正样本自动回流（M6 报告 v2 §1 第 4 项「部分满足」）、VQR `paramsSchema` 运行时 type/min/max 约束、复合非 `ServiceException` 子级隔离、Skill capabilities 发布期闸门（D-22）；E-5/E-6/E-7 分别由 E1/E2/E3 覆盖，不在此重复。

**非目标（边界外）**：

- **高级召回**（图谱多跳 / 向量 + BM25 / rerank）：条件触发归 M8，需配对评测收益证据（技术选型 §15）。
- **多域组合判定实现**（R-31）：首发单域口径不变，M7 只做边界声明与探针占位；判定实现随多域 ADR。
- **CopilotKit Headless 切换**：ADR-0010 决策维持，观察项非阻塞。
- **真实用户试运行 / 生产发布**：属 M8；M7 只对评测与观测负责。
- **评测集边做边改**：test 集冻结后只允许「升版 + 归档 + 登记哈希」，不允许就地改题（ADR-0005）。

## 3. 设计

### 3.1 评测运行模型与版本锚定

每次评测运行必须锚定并记录：`testSetVersion + contentHash`、生效清单 `manifest_id + contentHash`、策略快照版本、编译器版本、时间解析器 / 文案模板 / Scenario / Skill / VQR 版本、**模型名 + 参数（温度/重试/超时）+ prompt 版本**、执行路径（`llm` / `deterministic_fallback`）。运行产物落 `docs/06-verification/evaluation/`，文件名带版本或日期，**不得覆盖历史证据**（T55-3 教训）。

- 统计口径沿用 [评测统计口径 v1](../../06-verification/evaluation/评测统计口径-v1.md)：主指标分母不含 skip；分层小样本如实出 Wilson 下界，不冒充统计显著。
- 集合隔离：dev / validation / test / challenge 四集合不得混用；LLM 路径调整 prompt 或模型后，只允许在 dev/validation 上迭代，test 集运行次数与结果全量留痕。

### 3.2 LLM 路径评测（E-7）

- **运行前提**：稳定模型服务可用（base-url / api-key / 模型名三件套），模型版本与参数在运行前冻结；同一 test 集**多次运行**（次数见决策 4），逐次留痕，统计口径按运行维度聚合。
- **路径判定**：请求实际走 `ontos.agent.enabled=true` 的编排链路；任何因模型不可用、超时、解析失败而落到降级路径的请求，必须标记 `fallback_reason`，**不得计入 LLM 路径成功率**。
- **对比口径**：同一 test 集分别跑 LLM 路径与确定性降级路径，报告并列展示；差异归因到「意图/澄清/多轮合并」与「编译执行」两段，不合并结论。
- **失败分类**：模型不可用、超时、Proposal 合法性拒绝、DSL 校验拒绝、执行拒绝、文案/终态不符；每类给出样本与复现命令。
- **成本**：按 token 用量统计单题成本与总分位（P50/P95），与预算对比；预算阈值见决策 8。

### 3.3 E-5 品类粒度实现口径（决策 1）

按 [ADR-0016](../../01-decisions/ADR-0016-品类维度与订单事实指标的粒度边界.md) 二选一，**决策前不改清单结构、不放宽规划器**：

- **方案 A（订单项级指标）**：新增 `order_item` 粒度指标（销量/订单项金额），明确「订单项口径」，与订单级指标分列；品类维度只允许与订单项级指标组合。
- **方案 B（订单级去重语义）**：定义「按订单去重后再分组」的口径，需证明可解释（金额不重复计、计数按订单去重），并在指标契约与文案中写明。
- 落点：清单指标定义 + `allowed_dimensions` / 粒度校验 + DSL 契约 + test 集哨兵 2 题（转正例或维持拒绝并登记）+ Scenario/Skill 能力宣示。

### 3.4 E-6 auto 入口场景资产（决策 2）

- 发布至少一个 `entry_mode=auto_if_confident` 的场景资产（`entry_hints` 精确/子串唯一命中 + scope 收窄 + `frozen_calibers`），沿用 M6 决策 4 的确定性置信口径（不引入 LLM 置信度数值）。
- 补 ≥3 道 auto 入口 test 题（现有 0 题），覆盖：唯一命中自动进入、多命中回退自由问数、无命中回退；路由单测 + 端到端各至少 1 例。
- 资产发布走既有 dry-run / 确认 / 激活链路，清单升版并登记哈希。

### 3.5 对抗防线专项

在 M6 已有探针基础上扩展，保持「全拒 + 零泄露」：

| 攻击面 | 新增重点 |
|---|---|
| 提示注入 | 中文/英文/混合注入族、系统提示泄露、工具参数注入；LLM 路径与降级路径分别验 |
| 跨轮差分 | 逐步收窄、差分对、跨会话规避（session 级清零后 user 级仍拦截） |
| 跨域组合 | 首发单域边界声明 + 探针占位（R-31，多域 ADR 前不做判定实现） |
| 能力边界 | 候选集外资产、未发布 Skill/VQR、越权 Scenario、伪造确认回传 |
| discovery | 诱导执行、候选集外 ID、拒绝路径不得泄露存在性 |
| LLM 路径新面 | 工具调用越权（不得暴露 `execute_query`）、上下文污染、输出解析降级、模型不可用时的 fail-closed |

判据：严重越权与敏感数据泄露 **0**；存在性泄露 **0**；跨轮差分泄露 **0**；跨域组合违规 **0**（单域边界内）；注入成功 **0**；应拒答而执行 **0**。

### 3.6 失败看板闭环与纠正样本回流（M6 附条件项）

- **状态机**：`open → triaged → fixed → regressed / ignored`（只追加事件、当前态可查；租户隔离不变）。
- **回流 API**：审核后将失败样本写入**回归集**（dev/validation），生成样本 ID 与来源链接；**禁止直接写 test 集**（test 集冻结，只能升版）。
- **根因分类**：意图/澄清、Proposal 合法性、DSL 校验、编译、执行、权限/策略、文案/终态、模型不可用；与五维下钻联动。
- **闭环证据**：登记 → 分类 → 修复 → 回流 → 回归运行通过（或豁免记录）全链 E2E。

### 3.7 可观测与 SLO

- 复用 AgentScope OTel / Studio + Spring Boot Actuator，**不自研埋点**；trace 增加 LLM 调用段（模型名、耗时、token、fallback_reason），与 `X-Request-Id` / MDC traceId 关联。
- 指标：P50/P95/P99 延迟、rps、错误率、超时率、token 成本、缓存命中率、失败样本数；按 `scenario_entry_mode` / `query_shape` / `risk_type` 可切分。
- 压测：沿用三档并发（1/8/16）+ LLM 路径抽样（成本受限），SLO 阈值**看正式结果前冻结**（决策 8），不得事后下调。

| E-6 auto 入口 | ≥3 题 + 路由单测 | 唯一命中/多命中/无命中 |
| 对抗回归 | 五类既有 + LLM 新面 ≥12 探针 | 全拒、零泄露 |
| 失败看板闭环 | 登记→分类→修复→回流→回归 1 条全链 | 自动回流（非流程声明） |
| 可观测 | trace 关联（含 LLM 段）+ 三档压测 | §19 工程可用性 |

证据规则：运行产物带 `testSetVersion/contentHash`、清单哈希、模型参数与运行时间；文件名版本化，不覆盖历史（T55-3）；报告引用证据哈希前 16 位。

## 7. 风险与回退

| 风险 | 回退 |
|---|---|
| LLM 不稳定导致评测不可复现 | 固定模型版本/温度/重试/超时；多次运行统计；无效运行单独登记，不并入成功率；不放宽判据 |
| 评测成本超预算 | 只跑 test 集 + 抽样分层；缓存命中复用；预算上限前置冻结（决策 8） |
| 纠正样本回流污染 test 集 | 集合隔离：回流只写 dev/validation；test 集只升版；回流需审核并留痕 |
| E-5 决策拖延阻塞 W1 | 决策 1 未定档则维持 2 题 skip 与拒绝判据，W2/W3 可并行；不得临时放宽规划器 |
| 多域/R-31 未触发，跨域判据无法实测 | 只做边界声明与探针占位，验收报告如实登记，不伪造跨域结论 |
| LLM 路径暴露 `execute_query` 或工具越权 | 工具白名单 + 执行只在编排代码内部（M5 F-5）；LLM 工具越权探针进 T3.2 |
| 新增 `ontos-module-eval` 破坏架构 | 优先扩展 `system` + `scripts/verify`；确需新模块先改 ArchUnit 规则并说明理由（AGENTS §2） |
| trace 自研埋点重复 | 复用 AgentScope OTel / Studio + Actuator；只补 LLM 段与成本字段 |

| # | 决策点 | 建议档 | 影响 |
|---|---|---|---|
