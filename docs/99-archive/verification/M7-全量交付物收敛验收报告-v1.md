## 3. 口径声明（诚实性，不得事后追认）

1. **执行路径**：全部评测固定于**确定性降级路径**（`ontos.agent.enabled=false`，M5/T3.1 降级合同）——与冒烟 v2、正式评测集 v4 同口径。语义级多轮合并/纠正覆盖、OUT_OF_SCOPE 文案判定等属 LLM 编排职责，降级路径按安全底线判据（逐轮合法终态/不编造执行）校准并逐题写明；LLM 路径评测归 **E-7（M7 后续项）**，需稳定模型服务与多次统计运行。
2. **不得混淆集合**：dev/validation 结果（Golden、冒烟、复合回填）未计入 test 主指标分母；challenge（对抗）单独报告，未与 test 合并。
3. **skip 不进分母**：E-5 粒度扩散哨兵 2 题 skip；小样本分层（manual/cold_start/inherit 各 5、correction 12）Wilson 下界如实出表，不冒充统计显著。
4. **已知缺口**：E-5（品类×订单事实指标）、E-6（auto 入口资产前提）、E-7（LLM 路径评测）、CopilotKit spike（非阻塞观察项）、R-31（首发单域边界，非欠账）——均按触发点/负责人登记，不隐瞒不追认。
5. **基线系统对照（§13.3-1/2/3）**：本系统即 Text2DSL+确定性编译器架构，无独立基线系统可运行；配对对照只对可运行项做，N/A 项逐条声明理由。
