## 背景

M2 实施规格 v1.0 于 2026-11-08 09:37 冻结。冻结之后发生四件事，使规格正文的「状态类条款」与事实脱节：

1. **M1 定稿包收口**：M1 验收报告 v2 冻结（E1–E8 全满足）、ADR-0007/0008 负责人签字冻结、G2 三批 100% 维持关闭。规格 §2 仍写「M1 验收定稿：未定稿」「ADR-0007：草稿待签字」，§7 仍保留「ADR-0007 迟迟不签」风险行。
2. **T3.0 完成**：`ca61b26` 冻结了 funnel/yoy_mom 规格 v1，并在**已冻结**的 M2 规格 §4 正文原地标注「T3.0 已完成」。标注内容属实，但做法违反文档规范 §5「冻结不可原地改」。
3. **退出条件编号重复**：规格 §6 出现两个 E8（第二个是「验收报告关闭 E1–E7」），而 §6 结论写「未全部满足 E1–E8 不进入 M3」，验收口径不可判定。
4. **契约与评测集冲突**：T3.0 规格 §1.1 要求 `steps ≥ 2`，而 Golden 集 v2 的 `g-f02` 是单步漏斗正例；T3.0 规格 §3 要求 `analysis_params` 校验「进 W2」，但 W2 已结项、T3.0 才产出 Schema，工序倒挂；进度快照写「31 案例」，评测集文件实际 30 条。

以上均为**状态与口径问题**，M2 的范围、判据、阈值、任务结论没有变化。按文档规范，冻结文档不得原地改；沿用 [ADR-0002](ADR-0002-跨轮差分规则修订.md) 先例，以本 ADR 冻结生效解释。

## 决策

自本 ADR 冻结起，以下五条为 M2 实施规格 v1.0 的**生效解释**；与正文冲突处以本 ADR 为准，正文不改。

### 1. §2 依赖与前置闸门的状态更新（硬闸门已解除）

| 规格原文字 | 生效解释 |
|---|---|
| M1 验收定稿「未定稿」 | **已完成**：[M1 验收报告 v2](../06-verification/checklists/M1-验收报告-v2.md) 已冻结，E1–E8 全部满足 |
| ADR-0007「草稿待签字」 | **已冻结签字**，W3 编译器编码据此放行 |
| ADR-0008「草稿待签字」 | **已冻结签字**，W4 缓存读写据此放行 |
| 「全局闸门：§8 评审定稿前不启动 W2–W5 编码」 | §8.2 决策点已由负责人确认、规格已冻结 v1.0，闸门解除 |

其余行（首发清单、规划器、Golden 集升版设计）保持原文。

### 2. §4 状态标注追认与后续约束

- 追认 §4 中 `T1.1`、`T1.4`、`T3.0` 的「已完成」标注为有效状态（事实：M1 定稿包 + [funnel/yoy_mom 规格 v1](../04-specs/analysis-mode-funnel-yoy-mom-规格-v1.md) 已冻结）。
- **后续任何冻结规格的状态变更一律走本 ADR 或升版本，不得再原地改正文**。进度快照（append-only）是状态记录的唯一常规落点。
- [funnel/yoy_mom 规格 v1](../04-specs/analysis-mode-funnel-yoy-mom-规格-v1.md) 头块「负责人：项目组（M2/T3.0，待项目负责人评审确认）」为起草残留，**状态以「已冻结」为准**；该文字在规格下次升版时修正，本轮不动冻结正文。

### 3. §6 退出条件编号

第二个 E8（《M2 验收报告》关闭 E1–E7）视为 **E9 收口项**；退出判据仍以 **E1–E8** 为准，E9 是证据归档动作而非新增功能判据。M2 验收报告须按 E1–E9 逐条列出证据，避免「E8 满足但 E9 未做」的歧义。

### 4. §7 风险行关闭

「ADR-0007 迟迟不签」风险已消解（已冻结），该行在 M2 验收报告中登记为关闭；§7 其余风险与回退不变。

### 5. T3.0 与评测集的口径对齐

- [funnel/yoy_mom 规格 v1](../04-specs/analysis-mode-funnel-yoy-mom-规格-v1.md) 是两种模式 Schema 与语义契约的 SSOT，`steps ≥ 2` 为硬约束。
- Golden 集 v2 的 `g-f02`（单步漏斗）由正例改为**负例**：期望「步骤数不足 → 校验拒绝」。M2 验收按 30 条正/负例总数口径；进度快照「31」为笔误，按 append-only 以「更正」条目处理，不回改历史行。
- T3.0 规格 §3 的「`analysis_params` 校验进 W2」改判为 **W2 补齐阶段（W2.5）** 的必做项：W2 在 T3.0 之前结项，不能算已满足；补齐前 W2 不得判定为完成。
