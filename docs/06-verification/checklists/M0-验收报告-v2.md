## 3. 结论

**M0 退出判定：通过。** G1–G8 全部关闭（G2 为 [ADR-0006](../../01-decisions/ADR-0006-G2有条件关闭与重开口径.md) 记载的签字有条件关闭，重开口径可判定）。

按实施规格 §6，自本报告出具起：**允许进入 M1 编码；真实数据测试的解禁仍以 §4 复验登记为边界**——
涉及真实敏感数据的功能测试须待 M4 完成 RLS 补验（#1 三项）与 #7 集成复验后方可执行，
demo 数据上的功能测试不受此限；#1 补验任一项不通过即恢复禁令（见 G1 行后果约定）。

深度审计（2026-11-07）对「通过」结论的三点口径保留，均已在 v2 中显式化而非掩盖：
G1 的 `#1` 限定范围折算（附后果约定）、G2 的规格外第三状态（ADR-0006 正式化）、
G5 的签字时序（ADR-0005 决策 3 如实登记）。
