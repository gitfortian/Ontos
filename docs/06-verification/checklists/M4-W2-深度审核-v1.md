## 4. E2E 证据（`PoC-07-M4W2回归-2026-11-09.json`，21/21）

- **T1 个体探针**：单行 pii lookup 即时转审批（1003000008）+ 审批单落库 + `individual_probe` 记账；
- **T3 精确差分**：identities 集合差 1 + 基数差 1 + 均>1 → 即时转审批 + `differential_instant` 记账（ADR-0002 决策 1，仍记账）；
- **T2 批量记账**：不同参批量逐次记账不触发（独立 user 窗口互不污染）；
- **T4 窗口触发**：existence 层计数达 T=4 拒答档（两层独立判定取档位较高者）；触发后窗口持续拒答——**含缓存命中路径**（临时冻结语义）；
- **T5 审批闭环**：触发返回审批单 ID → 自审批禁止（1003000010）→ 决策人批准生成放行指纹 → 携 `X-Ontos-Approval` 同参放行（code=0）→ 复用拒绝（单次有效）→ 换 filters 重新触发（指纹绑定生效）。
