## 2. 保留策略口径（G-5 决策记录）

- `audit_log` 为**只追加、无清理任务**（合规/追责），故「与 audit_log 同策略」= 默认 `eventRetentionDays = 0`，永久保留。
- 事件表增长风险（v1.4 §8）由运维显式开启保留天数兜底：扫描周期默认 `PT6H`（`ontos.ask.event-retention-sweep-interval`），`sweep()` 在保留天数 ≤ 0 时短路（无运行时 DB 开销）。
- 清理范围仅限 `ask_run_event`（重放事件），不动 `ask_run` 状态行与 `audit_log`（审计链完整）；删除量记 INFO 日志。
- cutoff 按**上海墙钟 + 带时区 OffsetDateTime**（`TIMESTAMPTZ` 列语义），不依赖 JVM 默认时区。
