## 3. R-31 域组合判定边界声明（消除「按需排期」悬空）

> 来源：M4 验收报告 §5「域组合（domain_combination_policy）无判定实现 | M5/M6 按需排期（E2 清单不含，表结构已保留）」。

| 维度 | 定档 |
|---|---|
| 首发口径 | **单域不变**（ADR-0004 §2.7）：首发仅交易域，跨域组合策略不启用、不判定 |
| 当前运行时行为 | 跨域请求按首发单域边界拒绝或澄清（test 集 cross_domain 族 8/8 拒绝；T5.2 P1/P2 场景越界全拒；PoC#1 RLS 探针在位） |
| 判定实现排期 | **随多域 ADR 立项**（触发点 = 多域资产/域组合策略进入方案并出 ADR）；触发前不实现、不「按需排期」悬空 |
| 数据与契约 | E2 清单不含 domain_combination_policy；表结构保留（不删字段、不造假数据） |
| 验收含义 | M6 验收不因「无域组合判定实现」扣分——这是 ADR-0004 已定档的范围边界，不是欠账；判定实现属于多域 ADR 的交付物 |
