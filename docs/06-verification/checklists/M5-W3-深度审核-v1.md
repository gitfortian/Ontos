## 2. run 状态机（§3.7）

- **合法迁移显式枚举**（`AskRunStateService.TRANSITIONS`）并单测锁定：终态不可回退（FINISHED/FAILED/EXPIRED 无出边）、PENDING→FINISHED / WAITING_APPROVAL→FINISHED 非法跳跃拒绝、DB 状态与应用期望不匹配 fail-closed（M4 G-4 教训全部落实）。
- **R3**：同会话存在 RUNNING/WAITING_APPROVAL run → 新 run 拒绝（1005000001，E2E 实测）。
- **R4**：启动扫描（ApplicationReadyEvent）RUNNING→FAILED、WAITING_APPROVAL→EXPIRED（对齐 M4 审批惰性过期模式）。
- run 创建 = turn 占用（W1 乐观锁链路）：**按会话当前 turn_index 占用**（实施期 W3-2 修正——请求头 X-Ontos-Turn 是轮次声明，不做占用基准）。
