## 3. 语义确认（登记不改）

- **触发即建单、令牌决定放行**（M4 语义）：重放查询再次触发敏感判定时会**再建一张审批单**（留痕），令牌消费成功即放行——遗留 PENDING 单属设计内行为（`SENSITIVE_QUERY_EXPIRED` 文案提示「审批单在有效期内仍可批准」与此衔接）。
- **重放是新执行**：request_id 换新（`{traceId}-replay`）——request_id 是幂等键，原 ID 已被首次触发的 REJECTED 占用。
- **POST 同步等待 30s**：审批等待可能更长（TTL 15min），超时返回 waiting 中间态，终态经事件重放通道跟踪——客户端协议（W5/T5.3 前端）按此约定。
- **敏感收尾不走 FAILED 兜底**：`SensitiveClosedException` 携带已装配终态直通返回（run 状态已由收尾分支显式迁移），避免「结果未交付停在 EXECUTED」类回放假象（M4 G-4 教训的正向应用）。
