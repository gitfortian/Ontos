## 4. 语义确认（登记不改）

- `authorizedAssetIds` 是瀑布候选范围**预过滤**（宽集合定候选），执行路径逐资产 `check()` 完整保留——两层语义在 W1 审核已锁定，W2 遵守。
- 澄清候选要求 **2–5 个**（四要素契约）：单一模糊候选不构成澄清（候选不足时编排层按低置信处理）——契约字面执行。
- pinyin 45 条按定档 ③（M5 不引入拼音检索）全量 miss：**全量 Top-5 = 84.00% 与 PoC #5 字面 ≥95% 的差距是定档决策的直接结果**，非实现缺陷；拼音引入与否归 M7 评测后决策（数据已具备：非拼音 98.82% 证明检索层质量达标）。
- 授权域（authorizedDomains）收窄：M5 首发单 trade 域，瀑布用 `authorizedAssetIds`（租户快照 allowlist ∧ 角色交集）；跨域收窄随 M6 catalog 落地。
