### 2.1 规格逐条对照

| 规格条款 | 实现 | 结论 |
|---|---|---|
| §2.1 聚合锚点（metricId 必填 + allowed_modes 含 ATTRIBUTION） | `validateMode` 放行并在 `validateAttribution` 前置；编译器纵深防御再校验 | 符合 |
| §2.1 `attribution_window` 7d/14d/30d | 封闭枚举校验 + interval 字面量（`cast('30 days' as interval)`） | 符合 |
| §2.1 `model` 首发仅 last_touch | `first_touch` / `linear` → `ATTRIBUTION_MODEL_NOT_IMPLEMENTED`（1002000040），其他 → `DSL_INVALID` | 符合 |
| §2.1 `touch_event` 必须声明 channelPropertyId | 校验器要求属性已发布、可过滤、与事件映射同表；编译器再校验 | 符合 |
| §2.1 维度：渠道 + 指标同表 | `dim.channel` 特殊（值取 `channel.name`）；其他维度必须 `metric.table` 同表，否则 `ATTRIBUTION_DIMENSION_UNSUPPORTED` | 符合 |
| §2.1 `timeRange.field` = 转化事件 timeProperty | 服务端回填；客户端提交 timeRange 立即拒绝；field 被换即拒绝 | 符合 |

| §2.2-2 last_touch 100% 权重 | 标量子查询 `order by occurred_at desc, dedup_key desc limit 1` | 符合 |
| §2.2-3 每笔转化独立归因 | `conversions` CTE 一事件一行，子查询逐行求值 | 符合 |
| §2.2-4 触点与转化同一时刻 tie-break | 窗口 `<` 排除同时刻；多触点同时刻按 dedup_key 降序取一（全序显式） | 符合 |

| §4 正例 ≥4 / 负例 ≥2 | Golden 归因段 **4 正 + 4 负**（未知事件 / 未实现模型 / 跨表维度 / 客户端 timeRange） | 符合 |

### 2.2 安全与确定性边界

- **不新增身份面**；归因指标走 METRIC 主资产策略判定（与 QUERY 同链路），维度走 DIMENSION 判定（含 `dim.channel`）。
- **物理列全部来自清单**：事件判定/时间/主体/渠道/标识/去重键、渠道名、指标列、关系列均经 `OntologySnapshot` 解析；
  指标表 ↔ 事件表的 Join 条件来自已发布 Relation（`ontology.Order.recordsEvent`），**不按命名习惯推断**，
  关系缺失或并列一律拒绝。
- **占位符**全部 `?` 参数化，interval 字面量来自封闭枚举。
- **人工审阅不可省**：本条流程在本任务中直接暴露了一个逐字比对测不出的缺陷（T14-1）。

## 3. 发现与处置

| # | 级别 | 发现 | 处置 |
|---|---|---|---|
| T14-1 | **P1 缺陷（已修）** | `attributed` CTE 的 `left join channel as ch` 条件与 `select` 仍用未限定的 `"channel"."id" / "channel"."name"` → PostgreSQL 会报 `missing FROM-clause entry for table "channel"`。**Golden 逐字比对（10/0 通过）发现不了**——SQL 文本自洽，只有人工审阅 + 真库执行才暴露 | **已修**：JOIN 后统一用别名 `ch` 限定（`ch.id` / `ch.name`），重新回填 Golden 并真库执行验证（`code=0`） |
| T14-2 | P2 契约缺口 | 规格 §2 未定义 `touched_events` 语义，也未定义「转化事件无订单标识」的处置 | **登记 + 首发口径**：`touched_events` = 命中触点（`channel_name` 非空）的转化数（与 `converted_events` 互补，UNATTRIBUTED 行为 0）；无法关联订单的转化按 inner join 不计入并登记。下次规格升版补定义 |
| T14-3 | P2 计划偏差 | M6 规格 §3.6 规划「v12 = scenarios 完整段 + skills / vqrs 新段」，实际 **v12 = 渠道名称 + 事件去重键属性**（归因闭环的前置资产），scenarios/skills/vqrs 顺延 v13 | **登记**：属实现顺序调整，不改变任何契约；T2.2 发 v13 时同步 M6 规格 §3.6 的版本表（冻结文档以进度更正承载）。清单不可变，v12 已发布（hash `cc611e96…`） |
| T14-4 | P3 数据覆盖 | 真库 seed 中所有转化在 7d/30d 内均有触点，**UNATTRIBUTED 桶未被真库样例命中**（SQL 结构与单测覆盖） | **登记**：M7 评测集补「无触点转化」样例；本任务以 SQL 结构断言（`coalesce` + left join）与单测覆盖 |
