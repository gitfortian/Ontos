## 走查确认已有防线（登记不改）

- **并发同会话**：R3 闸门（非原子）由 turn 占用（原子 UPDATE）兜底——并发 POST 一个成功一个 409，不会产生双活跃 run。
- **HitlNotifier 连接生命周期**：onCompletion/onTimeout/onError 三路清理 + send 失败移除——无泄漏（M4 遗留「归 M5 处理」项核对通过）。
- **实时候选集对账 ≥ context_hash 对账**：每轮重新 resolve 后对账（更强），context_hash 作为凭证字段保留在候选集与事件中。
- **敏感触发后重放再建单**（M4 语义）：触发即建单留痕、令牌决定放行——遗留 PENDING 单与 EXPIRED 文案衔接，非缺陷。
- **并发审批占满执行线程池**（F-8 池 4 线程，每审批等待占 1 线程至决策/TTL）：单实例 M5 可接受；扩容/异步化登记 M6 运维面（与 §3.7 轮询在执行线程内的设计一致）。
- **turn 已占但 run 创建失败**（R3 竞态窗口）：跳号无害（turn 单调递增）。
