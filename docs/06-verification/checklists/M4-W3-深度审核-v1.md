## 3. 语义说明（登记）

- 令牌放行的结果会回写缓存；后续同参请求命中缓存同样记账判定——计数已超阈值故仍拒答，冻结语义
  在缓存回写后依然成立（W2-E2 修复的延伸验证）。
- EXPIRED 的 APPROVED 单不受惰性过期影响（过期只作用于 PENDING）——已批准未消费的令牌保持有效
  至单次消费，符合「审批通过即授予、消费即失效」语义；「批准后长期不用的令牌回收」归 M5/M6
  会话模型一并考虑。
- 计数器哈希的明文计数只在审批 payload（供决策人判断）与安全看板口径；审计与事件行只留哈希。
