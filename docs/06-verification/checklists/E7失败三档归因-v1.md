## 1. 三档定义

| 档 | 含义 | 主要处置 |
|---|---|---|
| **A 资产 / 词表 / planner** | 语义资产、候选表达、确定性降级或 planner 逻辑不足以表达正确意图 | 改资产 / 词表 / planner，不改题面期望 |
| **B 能力边界 / 提示词** | 执行器已有能力，但提示词或入口口径让模型主动拒绝 / 不知道如何表达 | 改提示词 v4 或候选上下文，不改执行器安全边界 |
| **C 模型表达 / 上下文** | 资产与口径均支持，但模型未能稳定完成语义映射、多轮继承或复合拆解 | 提示词示例 + 小批量模型复测；必要时评估模型能力项 |
| **H 工具链** | runner、断点、状态装配等评测/编排工具问题 | 修工具链，不计入模型能力失败 |

## 2. 29 个失败样本分布

| 失败族 | 题数 | 三档 | 结论 |
|---|---:|---|---|
| FUNNEL / RETENTION / ATTRIBUTION 自由问数 | 11 | **B** | ADR-0023 已定允许自由问数；提示词 v3 明确说“自由问数不支持”，模型按旧口径输出 `out_of_capability`。这是提示词 / 入口口径缺口，不是执行器缺能力 |
| LOOKUP / LOOKUP_BATCH | 7 | **B + H + C** | 属性直查示例已有但不足；布尔指标、批量、存在性表达缺少稳定示例。`t-lookup-bool-08` 另含 runner 断点复用与 planner 误用 QUERY，属 H |
| 多轮 followup / correction / incremental / diff | 4 | **C** | 模型在第二 / 第三轮未稳定继承前轮指标与过滤；需要提示词示例与会话投影表达约束 |
| COMPOSITE 转澄清 | 2 | **C** | 复合意图可拆但模型转澄清；需强化“两个独立可执行子意图”的示例 |
| 订单项销量 | 2 | **A + B** | 资产已在清单中，但模型未能稳定映射 `metric.order_item_quantity`；需要提示词示例 + 候选表达核查 |
| `gold` 等取值翻译 | 2 | **A** | 话术值与数据编码缺映射；应走资产 / 维度取值词表或别名，不允许模型猜编码 |
| YOY 模式选择 | 1 | **C** | 模型输出 QUERY 而非 YOY_MOM；提示词已有示例但仍不稳定，纳入小批复测 |

## 3. 修复排序

### P0 · 零 token / 低风险代码

1. **确定性 planner 布尔指标分支**
   - `metric.high_value_customer` 只允许 `LOOKUP / LOOKUP_BATCH`，不得进入 QUERY。
   - planner 应输出 `analysis_mode=lookup`、`boolean_metric_id`、`attributes`、`identity_value`。
   - 补单测：布尔指标 → LOOKUP；普通指标 → QUERY；身份缺失 → 澄清。
2. **runner 断点 request_id**
   - 已修复：`--resume` 时追加 `-x<resumeAttempt>`，避免复用服务端终态幂等键。

### P1 · 提示词 v4（先零 token 起草，再小批量复测）

1. 按 ADR-0023 移除“FUNNEL / RETENTION / ATTRIBUTION / LOOKUP_BATCH 自由问数不支持”。
2. 为四类模式补目标 JSON 形态、最小参数与 fail-closed 示例。
3. 为 LOOKUP 布尔判定、批量标识、存在性探针补示例。
4. 为多轮改口、增量条件、差分补继承示例。
5. 保持硬边界：只引用候选集 ID、不输出物理名 / SQL / 绝对日期、不猜编码。

### P2 · 资产 / 词表

1. `dim.customer_tier` 建立话术值 → 数据值映射（如「金牌客户」→ `gold`），或在候选澄清中稳定给编码。
2. 核查订单项销量在候选上下文中的可见性与别名。
3. 核查 FUNNEL / RETENTION / ATTRIBUTION / LOOKUP_BATCH 所需的事件定义、Rule、维度与技能上下文是否进入 retrieval 域候选。

### P3 · 小批量复测

1. 先跑 29 个失败题或按失败族抽样；不跑全量。
2. 并发 1、请求间隔、熔断、checkpoint。
3. 复测前冻结：清单版本、提示词 v4、runner v2.1+、planner 版本、候选域与工作区策略。
4. 结果仍只作诊断；是否替代 C-1 待 ADR-0022 终审。

## 4. 预期效果估计

| 修复 | 可直接改善 |
|---|---:|
| 提示词 v4 支持复杂模式 | 最多 11 题 |
| planner / LOOKUP 表达 | 最多 6 题（bool-08 属 H，另算） |
| 资产取值词表 | 最多 2 题 |
| 多轮 / 复合 / YOY 表达示例 | 最多 7 题 |

上限不等于预期；即使提示词 v4 后，复杂模式仍可能因参数缺失或模型遵循不足失败。

## 5. 结论

- 42% 不是单一“模型准确率低”问题；**38% 的失败样本（11/29）已被 ADR-0023 证明是入口口径 / 提示词冲突**。
- 优先做 planner 修复 + 提示词 v4 + 资产词表，再用小批量失败族验证；暂不花全量 API。
- 本归因不修改 test 集 v5，不解除 C-1。
