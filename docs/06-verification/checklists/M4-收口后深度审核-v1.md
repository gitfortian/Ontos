## 4. 全局复核中的语义确认（不改动，登记）

- **复合子意图 / dry-run 无令牌放行路径**：复合触发即转审批（子意图 filters 与单查不同，指纹几乎必不
  匹配，实现放行路径是假通道）；dry-run 是调试通道从严（触发即拒）——两者均为 fail-closed 正确口径。
- **`sensitive_query_event.reason_code` 列当前恒空**：细分触发分支统一走审计行 reason_code；
  事件行列预留（后续如需按事件行直读触发原因再启用，不提前加写路径）。
- **HitlNotifier 订阅生命周期**：`SseEmitter(0L)` 不超时，依赖连接断开回调清理；客户端半开连接
  在 M4 规模下可接受，长连接保活/超时策略归 M5 编排接入时统一处理。
- **修复前历史 EXECUTED 数据（128 条）**：属多轮 E2E 的史实数据，不回改；审计 reason_code 可区分。
- **OBL-M7**：状态维持 `deferred`、触发阶段 M6（ADR-0015）；本阶段未动 M7 台账与欠账口径。
