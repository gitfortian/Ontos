## 设计要点（审核确认）

- **approve 是留痕动作，不是状态迁移**：REVIEWING → REVIEWING 不在 `CatalogAssetStatus` 封闭迁移表内——审核人记录写入列与 definition（唯一真源同步），不触发迁移校验；
- **published 必有审核人**：校验器与发布闸门双侧拦截（清单侧 `SkillValidator` / 生命周期侧 `SCENARIO_REVIEW_REQUIRED`）；
- **approximation_of 跨模式**：被引用 Skill 必须在清单且与自身 analysis_mode 不同——同模式自我近似直接拒绝；
- **v14 未激活**：运行时消费（T3.2 注册表）就位前不改变生效清单——T3.1 只交付资产面，激活随 T3.2 后统一升版。
