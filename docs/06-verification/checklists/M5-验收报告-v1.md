## 5. 声明与遗留

- **执行模式声明**：本阶段 E2E/PoC 复跑在 `ontos.agent.enabled=false` 确定性链路执行（T3.1 降级口径）；LLM 路径与确定性路径共用同一 TerminalAssembler / 输出合同 / 完整性闸门，终态装配口径一致。真实模型端到端冒烟需凭据（`ontos.agent.model/base-url/api-key` 三件套就绪后执行），**登记为上线前检查项**（不阻塞 M5 验收——规格 T3.1 允许降级声明）。
- **拼音检索**：按定档 ③ 未实现；PoC #5 全量口径 84% 与字面 95% 门槛的差距是定档决策结果（非拼音 98.82% 达标），拼音引入与否归 M7 评测后决策。
- **并发审批占线程池**：run 执行线程池（默认 4）在多审批并行等待时会占满——单实例 M5 可接受，扩容/异步化登记 M6 运维面。
- **R-27 / R-29**：composite 透传不含变体拆分，随 M6 PoC #8。
- **OBL-M7**：状态维持 `deferred`（归 M6 核对，ADR-0015）；其提及样本 300 条回填义务已在本阶段 T2.4 落地并达标。
