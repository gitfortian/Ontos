## 1. 定位

本文件是「正式评估集另立文档」的**那张文档**（ADR-0014 背景第 4 条）。它只做三件事：

1. 把散落在各阶段验收下的题集**收编**为一个正式评测集，登记版本哈希——题集内容不在这里复制，判据不在这里重定义；
2. 给每个子集指定 **§13.2 四集合归属**（dev / validation / test / challenge）；
3. 对照 §13.2 的字段清单给出**当前覆盖度**，缺什么如实登记。

收编**不改变**任何子集的判据与冻结状态；子集修订仍走各自文档的升版流程，本文件升版登记新哈希。

## 3. 四集合口径（引用 §13.2，不复制阈值）

- **dev**：开发期回归，允许频繁修订与能力联动回填（Golden v1 → v2 → M3/M6 增量；冒烟集判据校准走升版）。
- **validation**：能力级判据集，冻结后随验收出回填结果；不用于对外成功率口径。
- **test**：主指标（任务成功率）**只按 test 集报告**；执行路径口径见 [test 集 v3 §1](test集-v3.md)（确定性降级路径）。
- **challenge**：安全与对抗，单独报告，**不与 test 合并计算**（§13.2）。
