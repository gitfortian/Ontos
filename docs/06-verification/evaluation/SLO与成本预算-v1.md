## 1. 冻结声明

- 本文件的阈值**在查看 M7 正式评测结果前冻结**（对齐 ADR-0005「先冻结、后看结果」），此后不得因结果不理想而下调。
- 判定采用**硬门槛**：任一层级出现错误/超时/超预算即 FAIL；不得用总体平均抵消单层失败（§13.4）。
- 阈值变更只能走「升版 + 修订记录」，或另发 ADR 说明为何原阈值不可判定；**不得临时放宽压测脚本**。

## 2. 延迟 / 错误率 / 超时率（确定性链路）

| 档位 | 并发 | 样本量 | P95 上限 | 错误率 | 超时率 |
|---|---|---|---|---|---|
| 基线 | 1 | ≥20 | **≤ 2000ms** | **0** | **0** |
| 中载 | 8 | ≥80 | **≤ 2000ms** | **0** | **0** |
| 高载 | 16 | ≥160 | **≤ 2000ms** | **0** | **0** |

- P95 上限沿用 M6 预冻结值（[压测证据 v2](压测-M6证据-v2.json) `sloFrozenBeforeRun.p95Ms=2000`），本次再次确认，**未下调**。
- M6 实测基线（2026-11-11，清单 `2026.11.10-sixteenth`）：并发 16 **P95=145ms**、242rps、0 错 0 超时；全样本 P95=126ms——作为 M7 回归下限（不得显著劣化，劣化 >30% 需在报告中解释）。
- 压测必须记录：清单 `manifest_id/content_hash`、并发档位、样本量、P50/P95/P99、rps、错误/超时计数；证据落 `docs/06-verification/evaluation/` 并按版本/日期命名，不覆盖历史（T55-3）。

## 3. LLM 路径成本预算（E-7）

| 项 | 冻结值 | 说明 |
|---|---|---|
| 单题 token 上限（prompt + completion） | **≤ 8,000** | 含系统提示、候选集与工具往返；超限即记 FAIL（不静默截断） |
| 单题 token P95 | **≤ 6,000** | 按 test 集 LLM 路径全部运行统计 |
| 多轮会话单轮增量 | **≤ 20,000** 累计 | 带上下文的多轮题按会话累计；超限记 FAIL |
| 运行次数 | **test 集 ×3** | 同 M7 决策 4；成本按运行聚合 |
| 金额预算 | **待 W2 模型确定后填** | 公式：`总预算 = 276 题 × 3 次 × 单题 token 上限 × 单价`；单价以实际模型服务价目为准，填入后本文件升 v1.1 |

- 成本来源：V19 `llm_call_trace`（`prompt_tokens` / `completion_tokens` / `fallback_reason`）；**统计写入失败不阻断业务**，但缺数据的分层不得报告成本结论。
- LLM 路径与确定性降级路径成本**分口径报告**：降级路径 token 成本 = 0，不得与 LLM 路径混算。
- 金额换算追加前，M7 验收只能判「token 预算」；金额预算未冻结时**不得宣告成本达标**。

## 4. 测量方法

1. **确定性链路压测**：`scripts/verify/load-m6.mjs`（三档并发）——每档固定样本量、同一清单、同一运行实例；`ontos.agent.enabled=false`。
2. **LLM 路径抽样**：`llm-test-runner.mjs`（W2 交付）记录每题 token；成本压测从 test 集分层抽样（每层 ≥10 题），避免全量成本失控。
3. **安全压测**：复用对抗探针全量（`adversarial-probe.mjs` / `adversarial-m6.mjs`），不计入延迟 SLO 分母。
4. 报告必须写明：环境（本地 PG18 / 部署环境）、清单哈希、脚本版本、样本量、并发档位、是否包含缓存命中。

## 5. 判定与报告

- 判定表：每档「P95 ≤ 上限 / 错误率 = 0 / 超时率 = 0」三项全过为 PASS；任一 FAIL 即整体 FAIL。
- 报告必须列出实测值、预算值、差值；不得只写「满足」。
- 与 M6 基线对比：P95 劣化 >30% 或 rps 下降 >30% 需在报告中给出原因与后续动作（不自动判 FAIL，但不得静默）。
- 失败样本按 §12.3 归因（编译/执行/数据库/资源），进失败看板。

## 6. 复核与变更

- 每次压测/成本统计必须引用本文件版本；证据哈希登记在 M7 验收报告。
- 模型/部署形态/缓存策略变更导致预算不再适用时：先发 ADR 说明，再升版本文件；**旧版本归档**，不原地改。
- 本文件不定义评测任务成功率门槛（唯一出处 [ADR-0005](../../01-decisions/ADR-0005-评测门槛与PoC执行责任.md)），只定义性能/成本口径。
