## 4. 修复项

1. `AskOrchestrationService.modelUserPrompt()`：将上一轮 `SessionProjection` 以语义槽位 JSON 注入模型输入，只含候选 ID 与相对时间，不含物理表列。
2. `AgentContextProvider.candidateVocabulary(userQuestion)`：支持问题感知候选视图。
3. `SessionCandidateContextProvider`：为异步修复轮保存本轮授权候选快照，解决 Reactor 线程拿不到请求线程 ThreadLocal 的问题。
4. LOOKUP / LOOKUP_BATCH 的 `attributes` 在通过输出契约授权词表时允许进入完整性对账；聚合路径仍严格限定检索候选。
5. runner 判据 v2.2：`LOOKUP_BATCH` 使用 `dsl.identities` 对账。
6. 编排层契约校验上下文改为 `modelUserPrompt(utterance, projection)`，与模型输入和异步修复轮保持一致。
