## 5. 外部 API 安全模式

后续外部模型评测必须遵守 [ADR-0022](../../01-decisions/ADR-0022-外部模型评测改为复杂度优先与API安全模式.md)：

1. 并发默认 1；并发 >1 只允许本地协议桩且必须显式 `--allow-unsafe-concurrency`。
2. 默认请求间隔 2000ms。
3. HTTP 429 / 5xx、网络错误、客户端超时、waiting 超时连续 3 次熔断。
4. 连续 8 次编排层 `degraded` 熔断。
5. 每题写入 checkpoint，支持 `--resume`；配置指纹不一致必须拒绝。
6. 默认只输出计划；真实调用必须显式 `--confirm`。
7. 性能指标只作观测，不作门槛。
