## M3/W4 文案模板服务（2026-11-09）

> 本文件 append-only：修正请追加「更正」条目，不回改历史行。

### 交付

- **`CopyTemplateService`（`service/copy`）**：原因码 → 渲染文案的唯一入口。
  查找顺序：`reasonCode + locale` → 同原因码任意 locale → `GENERIC`；全部落空 =
  新错误码 **`1002000034 COPY_TEMPLATE_MISSING`**（v7 等没有 GENERIC 的旧清单如实报缺，不硬编码文案）。
- **渲染边界（R-26 一并落地）**：占位符按发布期 `allowedPlaceholders` 白名单替换；
  **声明了但调用方没给值 → 回退 GENERIC 并记 WARN，绝不把 `{x}` 原文透给用户**；
  文本里未声明的花括号序列按**字面量**输出（是文案的一部分，不是待填充槽）。
- **端点**：`GET /api/v1/copy-templates/{reasonCode}?locale=zh-CN&<占位符参数>`，
  独立于错误响应（M3 规格 §8 决策 3：错误契约稳定，文案版本独立升级）；
  响应带 `fallback` 标记（true = 走了 GENERIC 兜底）。
- 复用 `effectiveReasonCode()`（v7 前缀派生），老清单的 OUT_OF_MANIFEST / NO_RULE / OUT_OF_SCOPE 可直接渲染。
