- **模型与校验**：`SemanticManifest.Metric` 新增 `caliberVariants`（variantId / alias / condition / version，
  condition 为「字段 + 算子 + 值」三元组，算子封闭枚举）；`ManifestPayload.CopyTemplate` 新增

  变体校验（ID 唯一、alias 非空、version 必填、字段存在且在指标授权内、**M3 只允许同表条件**、
  值数量匹配算子）与文案校验（(reasonCode, locale) 唯一、占位符必须白名单声明、

### Golden 脚本修正（配套）

- `check` 模式原样使用 gold 固化的 DSL（manifestId=回填当时版本），清单升级后会被
  `1001000001 请求清单与当前生效清单不一致` 整批拦住。现改为：check 时把 DSL 的 manifestId
  对齐到本次运行清单（SQL 比对不依赖 manifestId）；`--manifest-id` 缺省时自动取当前生效清单。
  这是脚本口径修正，不是判据放宽——逐字比对的 SQL / Join / 错误码完全不变。
