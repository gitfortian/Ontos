## 3. 设计

### 3.1 关键设计决策（评审确认项）

1. **Join 展开的确定性**：规划器返回 UNIQUE 路径后，编译器按路径边的 fromColumn/toColumn 顺序展开
   `JOIN`，禁止任何字符串拼接（对齐 ADR-0007）；基数校验：N:1 边做 many 端分组聚合，1:N 边
   沿路径方向判定粒度扩散，违反「一行一事实」的路径组合拒绝（v1.4 §8.2）。
2. **Rule 求值 = 编译期子查询展开**：布尔指标（ruleId）编译为
   `实体 IN (SELECT customer_id FROM orders GROUP BY customer_id HAVING SUM(amount) >= 50000)`
   形态的确定性子查询——规则表达式三元组（metricId/operator/threshold）→ jOOQ 结构化构造，
   禁止表达式字符串。
3. **累计敏感约束的 M2 边界（决策点，见 §8 待确认）**：M2 编译侧只做**敏感资产标记校验**
   （sensitive=true 的指标/维度拒绝批量导出形状：无维度分组 + 大 limit 组合 → 拒绝）；
   完整 §4.8 累计检测（sensitive_query_event 落库 + 窗口聚合）归 M4。
4. **口径变体**：gmv（支付口径）/ gmv_created（下单口径）是两个独立指标资产，variant_hint
   仅作检索与澄清用途，编译不读 variant_hint（每个指标 ID 自带完整口径定义）。
5. **复合意图**：agent 输出的 sub_intents 已带 sub_intent_id——M2 编译器逐子独立走
   校验→编译→执行，审计行携带 parent_request_id / sub_intent_id（M1 审计列已有）；
   子间依赖（depends_on）M2 只做「存在依赖即拒绝并转澄清」（结果编排归 M5/M6），无依赖子并行独立执行。
6. **缓存（ADR-0008）**：执行成功后按键回写（失败降级 WARN）；发布激活时 DELETE 旧 manifest 键。
7. **dry-plan 的 EXPLAIN**：对编译产物执行 `EXPLAIN (FORMAT JSON)` 真实获取计划与成本
   （只读不执行），成本阈值超限 → 计划标记 BLOCKED，dry-run 拒绝执行。

### 3.2 接口契约

**保持不变**：`/api/v1/query/compile`（dry-plan 语义强化）、发布链路、状态机、规划端点、AG-UI。

**扩展**（三端点语义，R4 澄清——dry-plan 不触数据表、dry-run 受限调试执行、execute 正式通道）：

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/v1/query/dry-plan` | 编译产物 + EXPLAIN 计划 + 成本标记，**不触数据表**（调试） |
| POST | `/api/v1/query/dry-run` | **受限执行**（更紧的超时/行数/成本闸门），调试用，返回结果 + 执行元数据 |
| POST | `/api/v1/query/execute` | **正式执行**（现有语义保留：审计 + 状态机 + 幂等），生产查询通道 |
| GET | `/api/v1/query/plan/{requestId}` | 按 request_id 回放最近一次编译产物（SQL + 绑定值 + 路径；**R5**：绑定值持久化见 W4） |

compile 现有契约字段不变，响应增加：`joins[]`（路径展开）、`cost`（EXPLAIN 摘要）、`mode`。

### 3.3 关键流程

**五模式编译形态**（Golden SQL 的形状基准，全部参数化）：

| 模式 | SQL 形状（jOOQ 构造） |
|---|---|
| query | `SELECT dims..., agg(metric) FROM <table> [JOIN path...] WHERE filters+time GROUP BY dims [HAVING rule] LIMIT ?` |
| lookup | `SELECT props... FROM <table> WHERE identity = ? LIMIT 1`（单实体，存在性敏感列走 displayHints） |
| lookup_batch | `SELECT props... FROM <table> WHERE identity IN (?,...) `（逐行存在性保护：缺失行原样返回不存在，不合并语义） |
| funnel | `WITH s1 AS (...), s2 AS (...) SELECT step, count ...`（步进 CTE，语义契约对齐 v1.4 §9.4） |
| yoy_mom | `SELECT period, value, lag_value OVER (...)`（窗口函数同比环比，时区/周起始按 ADR-0004 2.4） |

**时间窗来源（R7）**：相对时间经时间解析器（J 工作块）换算为 `resolved_range` 后填充
`timeRange`，`time_expression_raw` + `pattern_id` 进审计；绝对日期仅用户显式给出的
`explicit_range` 路径放行（T2.2 校验器区分二来源）。

**dry-plan / dry-run**：同一 `CompiledQuery` 产物（SQL + 绑定值 + 路径 + 成本）；dry-plan =
EXPLAIN 校验后返回；dry-run = 设 `statement_timeout`/`maxRows` 后执行。两者审计行区分 action。

## 7. 风险与回退

| 风险 | 回退 |
|---|---|
| 字符串拼接/隐式降级破坏确定性 | 代码评审对照 ADR-0007；Golden 逐字比对是照妖镜 |
| funnel CTE 复杂度失控 | 步进 CTE 模板化构造，禁止自由拼接；Golden 兜底 |
| 复合意图范围蔓延到 M6 | 本规格 §1 明确边界：M2 逐子编译+审计，结果编排归 M5/M6 |
