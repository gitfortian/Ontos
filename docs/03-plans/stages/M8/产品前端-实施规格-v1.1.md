## 1. 目标与非目标

**目标**：把「调试工作台」变成业务用户可直接使用的智能问数产品入口——以对话为主交互，澄清 / 审批 / 结果 / 历史全部产品化；治理页面原样收进后台分组，不新增管理功能。

**非目标**：移动 App、国际化、会话协作分享、消息编辑撤回（R2 拒绝）、可视化配置器、管理面功能增强、SSO 对接（列 M8）、CSV 导出（R1 F-8 砍除）。

## 4. 通道架构（run 事件流 = 唯一事实源）

### 4.1 Session–Run–Turn 三层模型

| 概念 | 定义 | 来源 |
|---|---|---|
| **Session（会话）** | 一次产品对话的容器；**前端在首问时生成并全程复用**（R1 F-5：现 ChatPanel 每轮换 session 导致指代消解 / 上下文继承 / 场景态全部失效——产品级缺陷，已修复规格化） | 前端 `crypto.randomUUID()`，形如 `web-<uuid>` |
| **Run（轮）** | 一次编排执行（首问 / 澄清回传 / 审批续跑各产生新 run） | 服务端响应 `runId`（**W-B0：统一回显**） |
| **Turn** | run 内的单次交互回合 | run 事件流的 TURN 边界（W0 spike 固化） |

UI 会话流 = 按 session 聚合、按 run 分段；段间以用户消息 / 澄清回传衔接。**回传动作在会话流中以系统消息呈现**（「你选择了：客户数」），不伪装成用户输入气泡（R2 G-13）。

### 4.2 事件事实源与恢复规则

1. **首问**：`POST /ask/runs`（utterance）拿 `runId`（W-B0）→ 订阅 run 事件（传输形态由 D1 定：AG-UI SSE 或 events 轮询 / SSE 化重放——事实模型不变）；**R4 H-1 红线：AG-UI SSE 与 events 重放只能是同一 `ask_run` 的传输差异，不得引入第二套 run 空间**；若 D1 选 A，须按 §0 硬约束完成 runId 映射 bridge；
2. **澄清回传 / 审批续跑**：`POST /ask/runs`（utterance + `clarificationChoice`）拿新 `runId` → 同样订阅；
3. **断线续播**：`GET /ask/run/{runId}/events?afterSeq=`（幂等）；**续播规则（R2 G-10）**：按 `seq` 去重、文本增量按 `messageId` 幂等拼接，已渲染部分不重复；
4. **WAITING_APPROVAL 跨标签页（R2 G-11）**：对话页对该态 run 以 5s 间隔拉取事件直至审批完成自动恢复；**多标签页 / 双端并发以服务端 run 状态为唯一裁决，前端不做审批结果乐观更新**；
5. UI 状态机只消费一种事件模型；SSE 与重放仅是传输差异。
6. **配置冻结联动（R4 §4）**：W0 的事件→终态映射清单须在 R3 D-A（×3 口径）定档后执行；若 D-B 选「关闭 MemoryConsolidator」，每 ask 调用数由 3 变 1，**映射清单必须重新固化**。

### 4.3 后端配套（W-B，除 W-B2a 外各 ≤2 天）

> **依赖（R4 H-12 修正）**：W-B0 → D1/W0；W-B1 → D4；W-B2a/b → D3/D10；W-B3 → W3；W-B4 → W4。W-B2a 因涉及全端点身份链，不套用「≤2 天」估算。

| 任务 | 内容 | 来源 |
|---|---|---|
| W-B0 | `POST /ask/runs` 响应统一回显 `runId`（**W0 前置**，R4 H-12） | R1 F-4 |
| W-B1 | `GET /api/v1/ask/sessions`：按用户聚合会话 + 会话→run 列表 | D4=a |
| W-B2a | **认证机制（R4 H-5：不是 ≤2 天小改）**：用户凭据存储 + 密码校验 + token 签发/校验 filter（签名/过期/续期）+ 401 语义对齐 + **PoC / live 基线脚本的 `X-Ontos-*` 头兼容**；token 驻留按 D10=a（httpOnly cookie，网关校验后注入头，业务代码零改动），移除 `TENANT_STORAGE_KEY` 的 localStorage 读写。开工前先出设计核对再排期 | D3=a、D10 |

## 6. 页面组件分解

### 6.1 对话主页

**会话状态机（R2 G-3/G-7，规格化）**：

| 状态 | 进入条件 | 输入区 | 允许动作 |
|---|---|---|---|
| `idle` | 会话创建 | 可输入 | 发送（→ running） |
| `composing` | idle 且输入非空 | 可输入 | 发送 |
| `running` | run 已提交未终态 | **禁用**（M5 R3 会话锁） | 停止跟随（→ running-stopped，**仅断开本地订阅，服务端 run 继续**，终态经重放补全后自动恢复渲染） |
| `running-stopped` | 用户点停止跟随 | **保持禁用** | 重新跟随（重新订阅） |
| `waiting_approval` | HITL interrupt | 禁用 | 审批卡操作（批准 / 拒绝 + 备注）；跨标签页轮询恢复（§4.2-4） |
| `clarifying` | 终态 clarification | 禁用 | 澄清卡点选 / 默认 / 跳过 → 回传（→ running 新 run） |
| `finished` | 终态 query / composite / discovery / out_of_capability | 可输入（追问，同 session） | 发送 |
| `error` | 网络失败 / 服务端错误卡 | 可输入 | 重试（重发同 utterance） |

组件清单：

- `ConversationStore`：**每会话固定 session_id**（首问生成 `web-<uuid>` 全程复用）；状态机实现；
- `ConversationStream`：按 run 分段消息列表，**200 轮长会话虚拟滚动**（R2 G-6）；
- `Composer`：多行、Enter / Shift+Enter、停止跟随、禁用矩阵随状态机；
- `TerminalCard` 五类（§5），**每卡独立 ErrorBoundary**（R2 G-13：单卡崩溃降级为错误卡）；
- `ClarificationCard`：四要素；回传协议 v1（assetId / `__default__` / `__skip__`）；自定义输入仅在候选为空时出现；
- `ApprovalCard`：批准 / 拒绝 / 备注；
- `ResultTable`：500 行上限前端分页（50 / 页）+ 列排序；**无 CSV 导出**；
- `ResultChart`（D5=a）：保守映射（列类型可用且维度恰 1 → 柱；时间列 → 线；0 维单值 → 大数字卡；其余只给表）；防误读：零基线、单位与口径标注、行数 < 3 不画图、**含负值正负分离标注、全零只给表**（R2 G-5）；
- `SessionStateBadge` / `EmptyState`（示例问题生成规则见 W6）/ `ErrorCard` + `RetryButton`。

### 6.2 会话历史（D4=a）

- `SessionList`（W-B1）：标题 = 首问前 24 字截断（R2 G-9）、最近时间、轮数；**数据源（R4 H-7）**：`ask_run` 无 utterance 列，W-B1 仅允许为生成标题读取 `RUN_STARTED.input.utterance`，响应只回标题不回完整 input；对话流其余位置不展示 `input`（A.4）；
- `SessionReplay` 只读（复用对话流渲染器 + 幂等事件重放）。

### 6.3 登录（D3=a）

- `LoginPage`（用户名 + 密码 + 租户）；roles → 导航显隐（G-14：`dev` 词表扩展随 W-B2b）；401 统一跳转。
- **token 驻留（D10=a / R4 H-2）**：登录页只提交凭据，服务端签发 httpOnly cookie；前端不写任何 Web Storage（D7 不破），刷新可恢复、多标签页共享登录态（支撑 G-11 跨标签页审批轮询）；退路选 b 时须补刷新恢复与同步用例。

### 6.4 开发者视图（D8=a）

- 折叠抽屉（dev 角色）；状态行展示候选域（full/retrieval）与词表规模、对账口径（R1 F-13）；事件日志 / DSL / 计划回放沿用现组件；**事件日志中的 `input.utterance` / `clarificationChoice` 须二次脱敏或默认折叠（R4 H-7，A.4）**。

## 7. 非功能标准

- **性能预算（R4 H-4 拆分）**：① **硬门槛**：用户可见首个反馈 ≤ 2s（提交后的本地即时进度指示 + 步骤摘要，不含模型）；500 行表格首渲染 ≤ 500ms；TTI ≤ 3s；**200 轮会话滚动无 >50ms 长任务**（R2 G-6）；② **观测项（不作 FAIL 门槛）**：模型首 token / 完整终态延迟（真模型实测约 8s、R-3 温度不可控，归 SLO 与 E-7）；③ 测量 = Playwright trace（W9），**固定使用确定性降级路径或协议桩**；
- **无障碍**：全键盘可达、焦点顺序、对比度 AA；
- **安全（前端输入不可信红线，R2 G-1）**：所有回传字段以服务端唯一裁决为准——澄清回传伪造、审批重放、越权 assetId 必须被服务端拒绝（M5 R5 回传校验 + M4 策略），E1 含伪造帧回归；
- **驻留泄露四条细则（R2 G-2，D7=a 落地）**：① 不写任何 Web Storage；② `pagehide` 不持久化敏感数据；③ 登出 / **租户切换**强制清内存态并跳登录；④ 注册 `pageshow` 检测 bfcache 恢复时强制刷新会话态；
- **兼容**：Chrome / Edge 最新两个大版本；两档断点；

## 附录 A：E1 十类代表性问法

1. 单指标聚合：「上个月各地区的成交金额」→ 结果表 + 柱图；
2. 多轮指代：追问「那华南呢」→ 上下文继承（metric / time）；
3. 澄清点选：泛化问法 → 澄清卡 → 点选候选 → query；
4. 澄清跳过：默认建议 → 跳过降级 → degraded 呈现；
5. 审批批准：敏感序列 → WAITING_APPROVAL → 内联批准 → 结果；
6. 审批拒绝：同上拒绝 → 拒绝文案终态；
7. 能力边界：清单外诉求 → out_of_capability 文案卡；
8. discovery：「我能查什么」→ 能力清单卡；
9. 复合意图：双意图一句话 → composite 分组卡（含部分失败同屏变体）；
10. 失败与伪造：断网重试成功 + **回传伪造帧被服务端拒绝**。
