## 追问：按最初完整规划要不要用向量/分词（2026-11-13）
- 结论：**规划里是要用的，但分两种性质**。分词 + PG 全文/模糊是「首发启用」（技术选型 v1.1 §4.5、组件表 L123-125；ADR-0009 冻结 IK）；向量是「条件启用、默认不用」（L122「M5 评测证明需要后启用」、PoC #6 退路「保持不启用」、roadmap L231「条件触发不排进主干」、M7 规格 v1.2 L53「高级召回条件触发归 M8」、L145 #18 混合召回 M7 标 N/A）。
- 版本演进：v1.0 前设想「业务/向量/全文/图统一 PG」（pgvector+zhparser+pgGraph/AGE 为默认组件，见 v1.1 §0 变更表 L24/L28/L40）→ v1.1/v1.4 把向量降级为条件项但保留分词首发 → M5 规格 F-2/F-3 把首发组件也砍成纯 Java 内存瀑布 → PoC #5 达标使向量闸门永不触发。
- 判定：「不用向量」= 规划默认路径，不算偏离；「不用分词」= 对首发规划的真实偏离，有规格修订依据但**冻结 ADR-0009 未收口 + M5 验收报告 §5 未点名该替换**（只登记拼音未实现），属欠账。
